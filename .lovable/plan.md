## الخطة النهائية: تحويل المعالج إلى 5 خطوات + مساري إكمال (إلكتروني/واتساب)

### الهيكل الجديد للمعالج

```text
1. البيانات الأساسية      (ضيف)
2. تفاصيل التأشيرة         (ضيف)
3. المتطلبات + السعر       (ضيف) — نهاية مرحلة الضيف
   └─ صفحة تخيير المسار:
       ├─ [إكمال إلكترونياً] → تسجيل سريع → خطوة 4
       └─ [إكمال عبر واتساب 💬] → توليد رقم طلب فوري + رسالة واتساب
4. رفع المستندات           (مسجّل فقط)
5. الدفع + checkbox الشروط  (مسجّل فقط)
```

**حذف:** خطوة "الشروط والأحكام" المستقلة (الخطوة 5 الحالية).

---

### التغييرات التقنية

#### 1. حذف خطوة الشروط المستقلة
- حذف `Step5Terms.tsx` من المعالج كخطوة كاملة
- تحويل الموافقة إلى **checkbox** داخل `Step6Payment.tsx` (يصبح خطوة 5)
- النص: «أوافق على [الشروط والأحكام] و[سياسة الخصوصية]» — روابط تفتح في modal جانبي بدون مغادرة الصفحة

#### 2. توثيق الموافقة على الشروط (طلب المستخدم)
إضافة لجدول `applications` عبر migration:
- `terms_accepted_at` (timestamptz) — وقت الموافقة الفعلي
- `terms_version` (text) — رقم نسخة الشروط (مثلاً `v2026.1`) للاحتفاظ بنسخة ملزمة قانونياً
- `terms_ip_address` (text) — IP العميل وقت الموافقة (سجل قانوني PDPL)
- `terms_user_agent` (text) — المتصفح/الجهاز

عند الضغط على زر الدفع (وقبل التحويل للبوابة):
- يُكتب timestamp + IP + user agent + version في الطلب
- إذا لم يضع علامة على checkbox → الزر معطّل
- يظهر في صفحة تفاصيل الطلب للموظف: «✅ وافق العميل على الشروط (v2026.1) بتاريخ ... من IP ...»

#### 3. صفحة تخيير المسار (بعد الخطوة 3)
مكوّن جديد `PathChoiceCard.tsx` يظهر داخل/بعد Step3:
- **بطاقة A — إكمال إلكتروني:** «ارفع مستنداتك وادفع خلال 5 دقائق» → يفتح `AuthGateModal`
- **بطاقة B — إكمال عبر واتساب:** «موظفنا سيكمل معك خطوة بخطوة» → ينشئ طلب فوراً بحالة `whatsapp_pending` ويفتح واتساب

#### 4. مسار الواتساب (الجديد — قنبلة المبيعات)
- استدعاء RPC جديد `create_whatsapp_order` يقبل بيانات الضيف من localStorage
- ينشئ profile مؤقت + application بحالة `whatsapp_pending` + رقم طلب `VF-2026-XXXX` فوراً
- **لا يتطلب تسجيل** — يكفي اسم/جوال (موجودان من خطوة 1)
- يفتح واتساب برسالة جاهزة تتضمن رقم الطلب + الدولة + نوع التأشيرة
- Trigger `notify_admin_on_whatsapp_order` (موجود مسبقاً ✅) ينبّه المشرفين
- العميل يستلم رقم الطلب SMS/واتساب لمتابعته لاحقاً عبر `/track`

#### 5. تحديث ApplicationContext
- تمديد `migrateGuestDraftToCloud()` لتحفظ checkbox الشروط تلقائياً عند الدفع
- إضافة `createWhatsAppOrder()` كمسار بديل عن المسار الإلكتروني
