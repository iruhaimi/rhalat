## خطة: إصلاح زر التفعيل وإضافة جدول ساعات عمل مفصّل

### المشكلة الأولى: زر التفعيل/التعطيل
**السبب الجذري:** سياسة الرؤية الوحيدة على جدول `footer_settings` هي:
```
SELECT ... USING (is_active = true)
```
عندما يضغط المالك على زر التعطيل، الـ UPDATE ينجح فعلاً، لكن السياسة تخفي الصف فوراً عن لوحة الإدارة لأنه أصبح `is_active=false`. النتيجة: العنصر يختفي ولا يعود ظاهراً ولا يمكن إعادة تفعيله.

**الإصلاح (migration):**
- إضافة سياسة جديدة `SELECT` للمشرفين الكبار (Super Admins) لرؤية جميع الصفوف (المفعّلة والمعطّلة).
- السياسة الحالية للعامة تبقى كما هي (يرون فقط المفعّل).

### المشكلة الثانية: ساعات العمل
الحقل الحالي `working_hours` نص حر واحد ("يومياً: ١٠ ص - ١٠ م"). يحتاج إلى:
- جدول لكل يوم من أيام الأسبوع (الأحد..السبت)
- لكل يوم: مفتوح (مع وقت بداية/نهاية) أو مغلق

**الإصلاح في `src/pages/admin/FooterManagement.tsx`:**
- اكتشاف العنصر بـ `key === 'working_hours'` تلقائياً.
- بدل زر القلم العادي، يفتح Dialog مخصص فيه:
  - 7 صفوف (أحد، اثنين، ثلاثاء…)
  - لكل صف: Switch (مفتوح/مغلق) + حقلَي وقت بداية ونهاية (نوع time) عند التفعيل
- يُخزَّن في عمود `value` كـ JSON:
  ```json
  {"sun":{"open":"10:00","close":"22:00"},"fri":{"closed":true},...}
  ```
- يُخزَّن في `value_en` الصيغة الإنجليزية مولّدة تلقائياً (للترجمة).

**الإصلاح في عرض الفوتر (`src/components/layout/FooterArabic.tsx` و`useFooterSettings`):**
- محاولة `JSON.parse` لقيمة `working_hours`؛ إن نجح → عرض جدول مرتب بالأسطر (مثلاً: "السبت - الخميس: ١٠ ص - ١٠ م، الجمعة: مغلق").
- إن فشل (بيانات نصية قديمة) → عرضها كما هي (توافق رجعي).

**سلوك التجميع الذكي:**
- إذا كانت أيام متتالية تشترك بنفس الوقت → دمجها ("السبت - الخميس: ١٠ ص - ١٠ م").
- الأيام المغلقة تُعرض منفصلة ("الجمعة: مغلق").

### الملفات المتأثرة
1. **Migration جديدة:** سياسة SELECT للسوبر أدمن على `footer_settings`.
2. **`src/pages/admin/FooterManagement.tsx`:** إضافة Dialog مخصص لساعات العمل + استبدال زر القلم بزر "تعديل الجدول" عند `key === 'working_hours'`.
3. **`src/components/layout/FooterArabic.tsx`** (وأي مكون آخر يعرض working_hours): دالة لتحويل JSON إلى نص عربي مرتب.
